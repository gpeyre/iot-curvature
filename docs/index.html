The quantity on the right

A fixed observation, a changing optimum

The bilinear cost is cu(x,y) = −xᵀ A(u)y. For uniform empirical measures, transport is an assignment problem. Write σ̂ for the observed pairing, fixed at u = ½. The displayed mean gap is

Ln(u) = 1n [ maxσ ∈ Sₙ ∑i xᵢᵀ A(u)yσ(i) − ∑i xᵢᵀ A(u)yσ̂(i) ].

It is nonnegative and convex in u: it is the maximum of affine functions minus one fixed affine function. At finite n, it is piecewise linear. A unique observed assignment remains optimal on an interval around ½, so a flat zero region is expected.

The curve shows 41 exact assignment evaluations, joined by straight segments. The selected point is evaluated separately. Interpolation can miss a narrow plateau or a corner; this is not a certified approximation to the full envelope. There is no entropy or spline smoothing.

Two sampling protocols

The marginals do not determine the observation

True paired samples. Draw Xᵢ ∼ N(0,I₂) and set Yᵢ = T(Xᵢ). The observed permutation is the identity. The pairs are independent samples from the population OT plan.

Independent marginals + assignment. Draw Xᵢ and Zᵢ independently, then set Yᵢ = T(Zᵢ). Compute an optimal permutation at u = ½ and freeze it. These matched pairs are not independent samples from the population plan.

For a direct comparison, the two schemes share the same source cloud and use the same seed. Their target clouds differ. Each has its own fixed reference pairing and its own empirical gap. One draw is displayed; differences may reflect sampling variability.

At δ = 0, paired samples satisfy Yᵢ = Xᵢ and the entire paired curve is zero for every positive semidefinite A(u). Independently sampled clouds generally do not have this exact property at finite n.

Models from the manuscript

Maps that are optimal by construction

Both maps are gradients of convex potentials and push the source to the stated target. The app uses the same formulas as the reproducible Python experiments.

A

Cosine perturbation

Ψδ(x) = ½‖x‖² + δ[cos x₁ + cos x₂ + cos(x₁+x₂)]
Tδ(x) = x − δ(sin x₁ + sin(x₁+x₂), sin x₂ + sin(x₁+x₂)).

For 0 ≤ δ < ⅓, the Hessian satisfies D²Ψδ ⪰ (1−3δ)I₂. Thus the paired observation is optimal at ½. Nonzero δ breaks the Gaussian degeneracy. Dividing by δ² changes only the vertical scale; it does not remove finite-sample plateaus or establish a uniform limit.

B

Gaussian to an annulus

q(r) = 1 − exp(−r²/2),
ρ(r) = √[0.8² + q(r)(0.85² − 0.8²)],
T(x) = ρ(‖x‖) x / ‖x‖.

The source radius is Rayleigh. Matching its quantiles to the radius of the uniform annulus 0.8 ≤ ‖y‖ ≤ 0.85 gives the monotone radial OT map. Its nonlinear radial profile permits population identifiability, while each finite sampled assignment still has a plateau.
